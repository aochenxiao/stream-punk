# 🖱️ 鼠标位置追踪器

这是一个美观的Windows窗口应用程序，用于实时追踪鼠标位置并在控制台打印坐标。

## 🎯 功能特点

### 基础版本 (mousPos.cpp)
- ✅ 实时鼠标位置感应
- ✅ 美观的窗口界面
- ✅ 控制台坐标输出
- ✅ 中文字体支持
- ✅ 渐变背景效果

### 增强版本 (mousPos_enhanced.cpp)
- ✅ 所有基础版本功能
- 🌈 彩虹色鼠标轨迹
- ✨ 更丰富的UI效果
- 📊 轨迹点数量显示
- 🎨 更美观的界面设计

## 🛠️ 编译方法

### 统一版本（推荐）
```bash
g++ -o mousPos_unified.exe mousPos_unified.cpp -lgdi32 -std=c++17
```

### 基础版本
```bash
g++ -o mousPos.exe mousPos.cpp -lgdi32 -std=c++17
```

### 增强版本
```bash
g++ -o mousPos_enhanced.exe mousPos_enhanced.cpp -lgdi32 -std=c++17
```

### 安全性修复
✅ 已修复 `localtime` 函数的安全警告，使用更安全的 `localtime_s` 替代

## 📖 使用方法

### 统一版本（推荐）
```bash
# 基础模式
mousPos_unified.exe
mousPos_unified.exe basic

# 增强模式（彩虹轨迹）
mousPos_unified.exe enhanced
```

### 基础版本
运行 `mousPos.exe`，在窗口内移动鼠标即可看到实时坐标信息。

### 增强版本
运行 `mousPos_enhanced.exe`，享受彩虹轨迹和更丰富的UI效果。

- **统一程序**: 一个程序支持多种模式，通过参数切换

- **GDI图形**: 使用GDI进行图形绘制
